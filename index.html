⚠ Read this — why your saves aren't sticking

This file is opened as a local download (file://), not inside Claude.ai, so it can't use real shared cloud storage — it falls back to your browser's local storage instead. That part usually works, but every time you (or I) download a new copy of this HTML file, it gets a different file path — and your browser treats each different file path as a completely separate storage bucket. So if you saved data into rugs_creation_dashboard_8.html and then opened rugs_creation_dashboard_9.html, the second file starts empty — your saves from the first one aren't lost, they're just sitting in storage tied to the old file, invisible to the new one.

Until this is hosted somewhere with a real, stable web address (see below), the one reliable way to carry your master data forward between file versions is: Download all masters as Excel below after you finish editing, and Upload that same Excel file the next time you open a new version of this dashboard. That workbook is a real file on your computer — it doesn't depend on browser storage at all, so it can't silently disappear the way this in-browser save can.

Fabric Master

Enter whatever unit your supplier quotes in (SQMTR / MTR / KGS). For MTR fabrics, add the roll width so the system converts to ₹/sqm automatically. For KGS fabrics, add the GSM. SQMTR fabrics need no conversion.

Yarn Master

Yarn is priced ₹/kg — that's correct as-is, since actual sqm cost depends on the GSM of each product (handled automatically in the calculator). "Reference GSM" here is optional and just for comparing yarns side-by-side; it doesn't affect any calculation.

Technique Master (weaving, tufting, stitching...)

Basis "sqm" = rate × area (used for carpets/rugs/bath mats, and for sqm-based facings like jacquard on cushions). Basis "piece" = flat rate per piece (used for stitching cushions, poufs, chair pads, throws).

Backing Master

SQM-priced backings (Latex, TPR, canvas pasting) need no conversion. KG-priced backings (Cotton TPR, Rubber Gel) need a GSM (coating weight per sqm) to auto-convert to ₹/sqm.

Carton Board Master

Rate is in ₹ (rupees), not paise — per square inch of board. Example: if your supplier quotes 4.5 paise/sqin, enter 0.045 here, not 45 (typing 45 would price it as ₹45/sqin — 1000× too high). All three boards below currently default to ₹0 until filled in, so carton cost will show ₹0 until you enter real rates here.

Zipper Master

Rate is ₹ per inch. In the calculator, pick the zipper type (Normal / YKK) and the price is calculated automatically as calculated length × this rate — no more looking up a fixed-length price.

Locked Quote Approvals

Quotes submitted with “Lock the Quote” appear here for the administrator. Review the costing and change its status to Approved or Rejected.

Stitching & Cutting Master

Fixed ₹/piece rate applied automatically for Cushion Cover, Filled Cushion, Floor Cushion, and Chair Pad — the merchandiser no longer picks a construction technique for these; this rate is added to every quote for that product category automatically. Edit here to change it for everyone.

Packaging Master

The Calculator's Packaging rate is fixed from here — no longer editable per-quote. For Cushion Cover and Filled Cushion, the rate instead comes from the Packing Method chosen below (bulk/single, hand-pressed/vacuum); for every other product, it's the flat rate here.

Packing Methods (Cushion Cover & Filled Cushion)

Rows are grouped by which product they apply to (the label text makes that clear) — only Label and Rate are editable, so the product mapping can't accidentally break.

Forwarding Master

Total ocean freight cost per container. The Calculator only actually uses the 40ft High Cube rate — it divides that by however many pieces the Container Loadability section (Section 7) works out fit in one 40ft High Cube, giving a ₹/piece forwarding cost. The other three rates are kept here for reference/quoting but aren't currently wired into the automatic calculation.

Quantity Buffer Master

A per-piece (or per-sqm for Carpet/Rug) USD price adjustment based on order size. Positive numbers add to the price (small orders cost more per piece to make); negative numbers subtract (bulk orders get a volume discount). The "100-300" / "≥ 50 sqm" tier is the MOQ baseline (buffer ₹0) — edit any row to change the step size or which tier counts as baseline.
